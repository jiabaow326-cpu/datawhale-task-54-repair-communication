# 参考答案与陷阱核验

## 参考事实边界

- 对话只是一段虚构聊天摘录，没有日期或完整上下文。
- 安禾在 20:05 的消息写“水槽里那口锅还在”；这能证明安禾在聊天中这样说，不能单独证明实际情形或责任归属。
- 当前约定 v2 规定：使用过共用锅的人原则上 21:00 前清洗；当晚不方便时说明情况并提出具体替代时间，双方再协商。
- 现有材料没有证明本次是谁用锅、安禾或小远过去重复了多少次、对方真实的感受和动机。
- 安禾确认自己的感受为着急/烦躁，关心的是共用安排清楚、变化时能互相说明。

## 埋设问题逐条核验

| 材料中的问题 | 可核对证据 | 处理结论 |
|---|---|---|
| v1 与 v2 规则不同 | v1 写 20:00、晚餐做饭者负责所有餐具和台面；v2 标为当前，仅涉及使用者清洗共用锅、原则上 21:00 前 | 执行 v2；不沿用旧版时间与扩展清洁范围 |
| v2 有重复件 | 当前版与重复件文件内容相同 | 不把复制件当作第二份协议或新证据 |
| 责任归属缺失 | 当前 v2 以“使用过共用锅的人”为责任条件，但材料没记录本次谁使用 | 不指责、不代替双方认定；消息中先询问 |
| “每次”是否成立 | 摘录中只有一次片段，没有此前次数记录 | 不写“总是/从来”，也不把它当事实 |
| 其他清洁义务 | v2 明确没有规定所有餐具或台面 | 不擅自要求对方洗所有碗或轮流擦台面 |
| 错误 AI 草稿 | 复用了旧版 20:00，添加“垃圾场”“从不守承诺”和禁止使用厨房的惩罚语 | 删除概括、羞辱、未经证实的责任和威胁，重新从已知材料起草 |
| 对方的感受、动机 | 无材料支持 | 不推断；只写安禾自己的体验 |

## 参考稿核对

完整草稿见 `results/参考修复沟通稿.md`。核对方式：

1. 开头引用聊天里确实出现的厨房锅具，不断言谁造成了问题。
2. 以“我有些着急”表达反思卡里的本人感受，并说明对共用安排清楚的需要。
3. 原样指出安禾自己的“你每次都这样，跟你说不通”带有概括与指责，并道歉。
4. 承认责任归属未知，先询问本次情况。
5. 提出协商具体时间的请求，并允许对方暂时不谈或提出别的时间。

这是一条草稿，不是使对方同意的技巧，也不是完整冲突解决方案。

## 发送前人工复核清单

- [ ] 这段话是否准确代表我自己的感受和需要？
- [ ] 事实是否能由当前材料支持？未知信息是否明确保留？
- [ ] 是否删除“总是、从来、故意、自私”等概括或动机判断？
- [ ] 请求是否具体、可拒绝，没有惩罚或隐含威胁？
- [ ] 现在是否适合沟通？对方可否晚些再谈？
- [ ] 若我担心人身安全或遭遇持续胁迫，是否先向可信赖的人或专业支持求助？
