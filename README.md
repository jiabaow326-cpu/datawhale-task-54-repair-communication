# U54 冲突后修复沟通：先理清事实，再写一条可商量的消息

本练习面向普通用户，使用完全虚构的合租厨房小摩擦，练习把可观察事实、自己的感受、在意的需要和具体请求分开。它不是心理治疗、调解或法律意见；AI 只提供可复核的文字初稿，不替任何人诊断、道歉、决定关系或代发消息。

## 文件地图

- `materials/`：虚构聊天摘录、当前/旧版共用厨房约定、重复件、个人反思卡、缺项说明和一个错误 AI 草稿。
- `tutorial/冲突后修复沟通实操教程.md`：五步教程，每步含缘由、任务、材料、可直接复制的提示词和完成标志。
- `reference/参考答案与陷阱核验.md`：版本与缺项答案、错误草稿逐句标注、参考修复稿及人工复核清单。
- `templates/修复沟通提示词模板.md`：可替换信息、事实、感受、需要和请求的通用模板。
- `results/参考修复沟通稿.md`：本场景的完整消息草稿。

## 练习边界

人物“安禾”“小远”、房屋和对话均为虚构。练习只起草安禾自己的消息，不揣测小远的想法，也不要求学习者发送。遇到威胁、暴力、跟踪、胁迫或人身安全风险时，不要用一条 AI 文案替代安全计划或专业支持；优先确保安全并寻求可信赖的人或合适的专业帮助。

## 方法依据

教程把非暴力沟通的常见四个组成部分用作练习结构：观察、感受、需要、请求；并提醒区分观察与评价、请求与要求。具体表达应因人和情境调整，不能把模板当成保证对方接受的技巧。
